# Exam Dashboard HS26

Prüfungsvorbereitung HS26 als installierbare Web-App (GitHub Pages).

- Seite: `index.html` (enthält keine persönlichen Daten und keinen Token)
- Daten: liegen im privaten Repo `hs26-dashboard-daten` (`data/hs26.json`) und werden über die GitHub-API synchronisiert
- Token: wird pro Gerät im Browser gespeichert (☁-Button in der App)
